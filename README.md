# Cylio Studio

> الإصدار 1.0.0 — أكتوبر 2026

محرّر في المتصفح لشخصيات مكوّنة من ست أسطوانات (رأس، جذع، ذراعان، رجلان) بهيكل مفاصل على طريقة R6: تعديل الشكل والمظهر، وضعيات العرض، حركات بإطارات مفتاحية، تجربة مباشرة في ساحة، وتصدير GLB.

**تشغيل مباشر:** https://limonatkh.github.io/Cylio/

## ما الذي يفعله

| القسم | ما يمكن تعديله |
|---|---|
| الشخصية › الشكل | عرض وعمق وارتفاع واستدارة كل جزء، المسافات بين الأجزاء، ربط العرض بالعمق، تعديل الجهتين معاً، تحجيم من المشهد |
| الشخصية › الوضعية | دوران كل مفصل حول نقطته الصحيحة (كتف، ورك، رقبة)، موضع الشخصية، وضعيات جاهزة، مقارنة بالوضعية الأساسية |
| المظهر | لون لكل جزء (ألوان جاهزة + المستخدمة مؤخراً + HEX + منتقي النظام)، الخامات (مطفي، ساتان، لامع، معدني، مجرّة)، الوجه (العينان والتوهّج والفم) |
| التحريك | مكتبة حركات (وقوف، مشي، ركض، قفز، سقوط، هبوط، تلويح)، خط زمني بمسارات للمفاصل، إطارات قابلة للتحديد والسحب والنسخ، نوع الانتقال، المدة، تسجيل تلقائي اختياري |
| التجربة | ساحة بمنصات، حركة بالكيبورد أو عصا لمس، انتقال سلس بين الحركات، سرعة مشي وركض محسوبة من طول الرجل |

- يبدأ مباشرة داخل المحرّر بشخصية افتراضية؛ المشاريع تُحفظ في المتصفح على الجهاز (IndexedDB)، مع مسودة استرجاع تلقائية للتعديلات غير المحفوظة.
- التراجع والإعادة لكل التعديلات، وتأكيد فقط عند فقد بيانات فعلي.
- واجهة عربية RTL؛ الأرقام والخط الزمني (من اليسار لليمين) معزولة الاتجاه.
- تصميم مخصص للجوال (مثل Galaxy M13): شريط أقسام سفلي، لوحة خصائص قابلة للسحب، وضع أفقي للتحريك.

## التشغيل محلياً

```bash
npm install          # أدوات البناء والاختبار فقط — التطبيق نفسه بلا اعتماديات تشغيل
npm start            # http://localhost:8080
npm run build        # dist/index.html ملف واحد (JS و CSS مضمّنان) + الخطوط
npm test             # اختبارات الوحدات (Node)
npm run test:e2e     # اختبارات المتصفح (Playwright) + فحص GLB بمدقق Khronos
```
